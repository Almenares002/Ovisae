El clima de Florida exige un diseño mecánico inteligente

Un sistema de aire acondicionado mal dimensionado no solo genera facturas de luz elevadas, sino que no enfría adecuadamente y se desgasta rápido. Nuestro enfoque se basa en el cálculo real de la carga térmica del espacio.

Diseñamos sistemas mecánicos que cumplen estrictamente con el Florida Building Code (Energy Code). Integramos los equipos, los ductos y la ventilación con el diseño arquitectónico y eléctrico para que todo funcione como un reloj.

Preguntas frecuentes

¿Es obligatorio cambiar el sistema de AC en una remodelación?

▼

Si la remodelación altera el volumen del espacio o agrega habitaciones, es muy probable que sí. El código exige que el sistema de climatización se adapte a la nueva carga térmica.

¿Qué es el Manual J?

▼

Es el método estándar de la industria para calcular la carga de enfriamiento de una vivienda.
